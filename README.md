# Snake Evolution - AI Enhanced Game

Современная версия классической игры "Змейка" с улучшенной графикой, звуковыми эффектами и AI-элементами.

## 🎮 Особенности

- **Современный дизайн**: Неоновая графика в стиле киберпанк
- **Адаптивность**: Работает на всех устройствах (десктоп, планшет, мобильный)
- **Звуковые эффекты**: Синтезированные звуки через Web Audio API
- **Система уровней**: Прогрессивное усложнение игры
- **Power-ups**: Различные усиления для змейки
- **Сенсорное управление**: Поддержка touch-управления для мобильных устройств

## 🎯 Power-ups

- **⚡ Speed Boost**: Увеличивает скорость движения
- **💰 Score Multiplier**: Удваивает очки за еду
- **👻 Phase**: Позволяет проходить сквозь препятствия
- **🐌 Time Slow**: Замедляет время

## 🎮 Управление

### Клавиатура:
- **WASD** или **Стрелки** - движение
- **Пробел** - пауза

### Мобильные устройства:
- **Свайпы** по экрану для изменения направления

## 🚀 Как запустить

1. Скачайте файл `snake-evolution.html`
2. Откройте его в любом современном браузере
3. Наслаждайтесь игрой!

## 🛠 Технологии

- **HTML5 Canvas** - для рендеринга игры
- **JavaScript ES6+** - игровая логика
- **CSS3** - стилизация и анимации
- **Web Audio API** - звуковые эффекты
